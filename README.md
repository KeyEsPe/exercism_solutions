
# Exercism Python Solutions

This repository contains my solutions to Python exercises from [Exercism](https://exercism.org/).  
Exercism is challenging from the very beginning, focusing not only on solving problems but also on **writing clean, readable, and maintainable code**.  

---

# Goals
- Strengthen Python fundamentals through practice  
- Apply **clean code principles** (DRY, KISS, SOLID basics)  
- Develop problem-solving skills step by step  
- Keep a visible track of learning progress  

---

# 🛠 Tech & Tools
- **Python 3.x**
- Exercism CLI
- GitHub for backup & progress tracking

---

# Why Exercism?
Unlike many platforms, Exercism emphasizes:
- Code reviews & mentoring  
- Readability over quick hacks  
- Incremental learning with real-world coding standards
